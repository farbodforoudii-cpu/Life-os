# زندگی من — Life OS

برنامه‌ریز و دفتر ثبت شخصی، آفلاین و نصب‌شدنی (PWA) برای آیفون و آیپد.

- نمای «امروز» با کارِ الان، بعدی و برنامه‌ی فردا
- نمای هفته مثل جدول برنامه‌ی ثابت: هر روز یک ردیف، ساعت‌ها از راست به چپ
- کار گذشته خودکار «انجام شد»؛ لغو با یک لمس، با «برگردون»
- افزودن با یک لمس از روی پرتکرارهای یادگرفته‌شده
- تاریخ شمسی، هفته از شنبه
- همه‌ی داده‌ها فقط روی دستگاه (IndexedDB)

**هیچ داده‌ی شخصی‌ای در این مخزن نیست.** اسم‌ها و برنامه‌ها فقط روی دستگاه کاربر ذخیره می‌شن.

اجرا به‌صورت محلی: `python3 -m http.server` داخل همین پوشه.
