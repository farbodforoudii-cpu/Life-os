# «زندگی من»: پروندهٔ پروژه

پروندهٔ ثابت پروژه: وضعیت، تصمیم‌ها، یافته‌های ممیزی و سؤال‌های باز. **هیچ نام مراجع یا دادهٔ شخصی در این فایل نیست.**

## پروفایل
- **هدف:** برنامه و دفتر کار یک مربی: جلسه‌های مراجع و کلاس، شیفت باشگاه، دانشگاه، وقت شخصی؛ بسته‌ها، قیمت، فاکتور و گزارش ماه.
- **فناوری:** PWA آفلاین، جاوااسکریپت خالص، IndexedDB، همگام‌سازی Supabase با کد ۲۵ حرفی (مشترک با «حساب من»)، GitHub Pages از `main`.
- **پیوند با «حساب من»:** `bill_*` و `month_*` از این‌جا، `pay_*` و `money_*` از آن‌جا (قالب: hesab-man `docs/ECOSYSTEM.md`).

## اعتبارسنجی
- `tests/learning.mjs`: هستهٔ یادگیری با دادهٔ ساختگی: شناختن کار از روی روز و ساعت، مدت از جلسه‌های اخیر، و سه نوع پیشنهاد الگو (افزودن، تغییر مدت، برداشتن).
- `tests/smoke.mjs`: فقط دادهٔ ساختگی. همهٔ زبانه‌ها و برگه‌های اصلی روی گوشی و آیپد، روشن و تیره، بدون خطای کنسول؛
  شماره‌گذاری بسته، قیمت (فهرست، تعداد نفر، قیمت خود جلسه)، جمع فاکتور، و انتقال دلیل‌های لغو.
  اجرا: `python3 -m http.server 8767` و بعد `node tests/smoke.mjs`.
- قبل از هر تغییر ظاهری: عکس و توضیح کوتاه، انتشار فقط بعد از تأیید.
